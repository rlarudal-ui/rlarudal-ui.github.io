**가상 머신(Virtual Machine,VM)**
VM은 하나의 컴퓨터 안에서 또 하나의 컴퓨터를 에뮬레이션하는 소프트웨어입니다. 

필요성
1. 하나의 호스트 머신에서 여러 개의 가상 머신을 실행할 수 있어 테스트하고자 하는 환경을 쉽게 구축할 수 있는 장점이 있습니다.
2. 가상 머신은 호스트 머신과 완전히 분리된 독립된 환경을 구성하기 때문에 일반적으로 악성 코드를 실행하더라도 호스트 머신에 영향을 미치지 않습니다.
3. VirtualBox는 스냅샷 기능을 제공합니다. 이를 통해 가상 머신의 상태를 저장하고, 빠른 복원이 가능합니다.

*호스트 머신이란?
실제 컴퓨터를 말한다. 반대로 호스트 머신 위에서 돌아가는 VM을 게스트 머신이라 한다.


**셸(Shell)**
셸은 사용자와 리눅스 커널 사이를 연결해 주는 통역사 입니다. 즉, 사용자에게 입력을 받고 운영체제의 핵심이 되는 커널이 그것을 프로그램으로 처리하면 그 결과를 유저에게 출력합니다.

리눅스에 들어가 ctrl + alt + T (윈도우,리눅스 기준) 단축키를 누르면 터미널이 실행된다. 위에 bash 셸이 자동으로 실행되고 셸 프롬프트가 뜨게 되는데 이는 셸이 명령어를 입력 받을 준비가 되었다는 것을 알 수 있다.

**<기초적인 명령어>**
1. sudo apt update
sudo apt update는 apt 명령어로 설치 가능한 소프트웨어 패키지 목록을 업데이트합니다. 그리고 각 소프트웨어 패키지 별로 어떤 버전을 설치할 수 있는지도 업데이트 합니다.

2. sudo apt upgrade
리눅스에 설치된 소프트웨어 패키지의 버전을 업그레이드 합니다. 오래된 소프트웨어 패키지에 존재하는 취약점은 보안 문제를 일으킬 수 있어 주기적으로 소프트웨어 패키지를 업그레이드하여 보안 문제를 예방하는 작업이 중요합니다.

3. id
현재 유저의 유저의 id와 해당 유저가 속해있는 그룹 id를 출력합니다. 리눅스 권한을 기반으로 파일을 읽고 쓰고 실행할 수 있기 때문에 주로 자신이 해당하는 권한을 가지고 있는지 확인하기 위해 사용하는 명령어입니다.

4.pwd
print working directory의 줄임말로 현재 작업 중인 디렉토리의 경로를 출력합니다. 

5. ls
List의 줄임말로 디렉토리의 내용을 출력하는 명령어입니다. 
* 'ls -l'을 실행하면 좀 더 자세한 정보를 함께 출력합니다. 
* 'ls -l /'을 실행하면 현재 디렉토리 뿐만 아니라 임의 디렉토리의 내용을 출력하는 것도 가능합니다. 

6. cd
change directory의 줄임말로 작업중인 디렉토리를 변경하는 명령어입니다.
* 절대 경로는 루트 디렉토리 '/' 를 시작으로 모든 경로를 적어서 표현하는 경로 입니다.
* 상대 경로는 현재 디렉토리를 기준으로 상위 디렉토리 또는 하위 디렉토리로 뻗어 나가는 경로를 말합니다. 예를 들어 'cd ..'는 현재 디렉토리에서 부모 디렉토리로 이동합니다. 가령 현재 디렉토리가 '/home/user' 일때 'cd ..'를 실행하면 '/home'으로 이동합니다.

7. mkdir
make directory의 줄임말로 디렉토리를 생성하는 명령어입니다.

8. touch
touch 명령어는 비어 있는 새로운 파일을 만드는데 사용합니다. 

9.mv
move의 줄임말로 파일이나 디렉토리의 위치를 옮길 때 사용하는 명령어 입니다. 파일이나 디렉토리의 이름을 변경할 떄에도 사용할 수 있습니다.

10. rm
remove의 줄임말로 파일이나 디렉토리를 삭제하는 명령어 입니다.
* 디렉토리 삭제는 '-r' 플래그를 추가한 'rm -r'로 수행할 수 있습니다.

11. cat
파일의 내용을 출력하는 명령어 입니다. 'cat 파일경로' 형식으로 사용할 수 있습니다. 

12. file
파일의 유형을 출력하는 명령어 입니다. 'file 파일경로' 형식으로 사용할 수 있습니다.

13. echo
셸에 유저가 입력한 텍스트를 출력합니다. 
* echo 명령어를 사용해서 파일을 생성할 수도 있습니다. echo 명령문 끝에 '> 파일명'을 이어 붙여 실행하면 파일명을 이름으로 가지느 파일을 생성하고 echo 뒤에 입력한 내용을 파일 내용으로 저장합니다.

14. cp
copy의 줄임말로 파일이나 디렉토리를 복사하는 명령어 입니다. 'cp 원본파일 새파일이름' 형식으로 사용합니다.
* 디렉토리를 복사할때는 '-r' 플래그를 붙인 형태인 'cp -r'으로 사용할 수 있습니다.

15. grep
전체에서 특정 문자열을 찾을 때 사용합니다. 'grep 특정문자열 문자열파일' 형식으로 사용할 수 있습니다.
(예시) 'grep root /etc/passwd'를 수행하면 /etc/passwd 파일에서 root 문장열이 포함된 행을 출력하게 됩니다.

16. man
manual의 줄임말로 특정 명령어의 메뉴얼을 보여주는 명령어입니다. 메뉴얼은 명령어 사용법, 옵션, 예제 등 유용한 정보를 담고 있습니다. 

17. crul
client URL의 줄임말로 서버에 데이터를 보내거나 서버로부터 데이터를 받는 데이터 전송 명령어 입니다. curl [옵션] URL 형식으로 사용할 수 있으며 HTTP,HTTPS,FTP 등 다양한 프로토콜을 지원합니다. 
* '-o file' : 전송 받은 데이터를 파일에 저장합니다.
* '-i' : 결과 값에 HTTP 응답 헤더를 포함합니다.
* '-X "method' : HTTP 요청 메소드를 지정합니다.
* '-d "key=value"' : HTTP POST 메소드로 데이터를 전송합니다.

**와일드카드(wildcards)**
와일드카드는 리눅스에서 임의의 다른 문자를 나타낼 수 있는 특수 문자들을 의미합니다. 주로 명령어를 다른 문지열로 대체하기 위해 사용합니다.

**리다이렉션(redirection)**
리다이렉션은 모니터에 나타나는 표준 출력 혹은 키보드로 입력하는 표준 입력을 다른 곳으로 변경하는 작업입니다. 주로 어떤 명령어의 결과를 파일로 저장하거나, 다른 명령어의 입력으로 전달하는 형태로 리다이렉션합니다.

< : 파일의 글자를 명령어에 쏟아붓기 (파일 읽기)

> : 명령어 결과를 파일에 쓰기 (덮어쓰기)

>> : 명령어 결과를 파일 끝에 붙이기 (이어쓰기)

| : A 명령어의 결과를 B 명령어의 입력으로 이어주기


**권한-유저와 그룹**
리눅스의 각 유저는 이름과 고유한 사용자 ID(UID)를 가지고 있습니다. 그룹은 말 그대로 여러 유저가 속할 수 있는 그룹으로, 이 역시 그룹 이름과 고유한 그룹 ID (GID)를 가지고 있습니다.

/etc/passwd 는 리눅스의 유저 정보를 담고 있는 텍스트 파일 입니다. 각 줄은 하나의 계정을 나타내며 콜론으로 구분된 7개의 필드로 구성됩니다.
필드구조( username:passward:UID:GID:comment:home_dir:shell)
(예) root:x:0:0:root:/root:/bin/bash
*비밀번호 표기: 과거에는 암호화된 패스워드가 직접 저장되었으나, 현재는 보안상 /etc/shadow 파일에 저장되며 통상 x로 표기됩니다.
*사용자 ID: 시스템이 사용자를 식별하는 고유 번호 입니다. 0은 관리자 계정을, 1~999는 시스템 및 서비스 전용 계정을, 1000 이상은 일반 사용자 계정을 뜻합니다.

/etc/group 파일은 리눅스 시스템에 정의된 그룹 정보와 각 그룹에 속한 사용자 목록을 관리하는 설정 파일입니다. 각 줄은 콜론으로 구분된 4개의 필드로 구성됩니다.
필드구조(group_name:passward:GID:user_list)
(예) adm:x:4:syslog,user
(해석) user 계정이 adm 그룹에 속해 있어 시스템 주요 로그(/var/log)를 읽을 권한을 가집니다.


**파일 및 디렉토리 권한**
각 파일과 디렉토리에는 소유자와 소유 그룹이 있습니다. 소유자는 유저가 해당 파일과 디렉토리에 얼마만큼의 접근 권한을 가질 것인지 설정할 수 있습니다. 그 권한으로 읽기, 쓰기, 실행이 있습니다.

(예) drwxrwxr-x 2 user user 4096 12월 2 13:38 dir
1. 첫번째 열 drwxrwxr-x :권한 플래그
d rwx rwx r-x 로 나눌 수 있습니다.
d는 문자 타입을 나타냅니다. d는 디렉토리, -는 일반 파일, l은 바로가기와 같은 링크 파일을 나타냅니다.
rwx는 소유자의 권한을 나타냅니다.
rwx는 소유 그룹에 포함된 유저들의 권한을 나타냅니다.
r-x는 파일 또는 디렉토리의 소유자 및 소유 그룹에 포함된 유저들을 제외한, 나머지 유저들의 권한을 나타냅니다.
+ 권한을 나타내는 3개 문자는 2진수나 10진수로도 표현이 가능합니다. 예를 들어 rwx는 2진수로 111이며, 10진수로 7입니다. r--은 2진수로 100이며, 10진수로는 4입니다.

2. 세번째 열 user : 소유자
위 dir 디렉토리의 소유자가 user 유저임을 알 수 있습니다.

3. 네 번째 열 user : 소유 그룹
리눅스에는 여러 사용자를 하나의 집합으로 관리할 수 있는 그룹 기능이 있습니다. 소유 그룹은 그룹 단위로 파일 또는 디렉토리에 권한을 부여할 때 사용합니다. 


**파일 및 디렉토리 권한 명령어**
1. chmod
chmod는 파일 권한을 변경하는 명령어입니다. root 유저 혹은 파일의 소유자만 실행할 수 있습니다. 'chmod 권한 파일명' 형식으로 사용합니다. 권한을 표현할 때는 권한 플래그를 10진수로 표현하거나 기존의 권한에 문자를 더하거나 뺍니다.
(예) chomd 764 hello
(해석) hello 파일에 소유자 권한은 rwx=7, 소유 그룹 권한은 rw-=6, 일반 유저 권한은 r--=4로 바꾼다. 즉, -rwxrw-r-- 1 user user 13 12월 2 13:05 hello가 된다.
(예) chomd g+x hello 
(뜻) hello 파일에의 소유 그룹에 x(실행) 권한을 부여한다.

2. chown
chown은 파일 소유자 혹은 소유 그룹을 변경하는 명령어 입니다. 시스템 보안상 `root` 유저(또는 `sudo` 권한)만 실행할 수 있습니다.
* 기본 형식 :`chown [사용자명][:][그룹명] 파일명`
* 소유자와 그룹을 구별할 때 점(`.`) 대신 **콜론(`:`)을 사용하는 것이 현재 표준**입니다. (계정 이름에 점이 들어갈 경우 발생하는 오작동 방지)

<상황별 사용 예시>
1. 소유자만 변경할 때
`sudo chown [사용자명] 파일명`
*(예: `sudo chown root hello` → 소유자를 root로 변경)*
2. 소유자와 소유 그룹을 한 번에 변경할 때
`sudo chown [사용자명]:[그룹명] 파일명`
*(예: `sudo chown user:user hello` → 소유자와 그룹을 모두 user로 변경)*
3. 소유 그룹만 변경할 때
* **`chgrp` 전용 명령어 사용:** `sudo chgrp [그룹명] 파일명`
* **`chown` 명령어 활용:** `sudo chown :[그룹명] 파일명` *(콜론 앞에 소유자명을 비워두고 작성)*
4. **하위 디렉터리 및 내부 파일 전체 변경할 때**
* 대문자 `-R` (Recursive) 옵션을 추가하면 해당 폴더 내부의 모든 파일과 하위 폴더까지 한 번에 적용됩니다.
*(예: `sudo chown -R user:user my_folder`)*


**특수 권한**
rwx 외의 특수한 권한 3개
1. setuid: 일반 사용자가 파일을 실행하면 파일 소유자 권한으로 실행됩니다. 소유자의 실행 권한에 x 대신 s 문자로 나타냅니다. 대문자 S로 표시되는 경우에는 setuid가 걸려 있으나, 실행 권한이 없는 경우입니다.
*대문자 S는 "SetUID를 켜두긴 했는데, 정작 실행 권한(x)을 안 줘서 아무 소용없는 껍데기 상태"를 나타내는 일종의 경고 표시입니다.

2. setgid: 일반 사용자가 파일을 실행하면 파일 소유 그룹 권한으로 실행됩니다. setgid는 소유 그룹의 실행 권한에 s문자로 나타냅니다. 마찬가지로 실행권한이 없으나 setgid가 걸려 있는 경우 대문자 S로 표시됩니다.

3. sticky bit: 디렉토리에 sticky bit: 디렉토리에 sticky bit를 설정하면 파일 및 디렉토리 소유자와 root 사용자 외에 일반 사용자가 파일을 삭제할 수 없습니다. 주로 공용 디렉토리에 사용합니다. t 문자로 나타내고 이 역시 실행권한이 없는 경우에 T로 표시합니다.

+ 특수 권한을 지정할 때는 권한 플래그 맨 앞에 숫자를 붙여 나타냅니다. setuid는 4, setgid는 2, sticky bit는 1 입니다.


**디렉토리 구조**
1. 루트 디렉토리 '/'
루트 디렉토리는 리눅스의 최상위 디렉토리를 말하며, 절대 경로는 / 입니다. 'cd /; ls -l' 또는 'ls -l' /를 실행하면 루트 디렉토리에 존재하는 파일과 디렉토리들을 볼 수있습니다.
*/bin : 일반 유저가 사용할 수 있는 기본적인 명령어나 프로그램을 담고 있는 디렉토리입니다.
*/boot : 시스템 부팅에 필요한 파일들을 담고 있는 디렉토리 입니다.
*/dev : 리눅스에서는 컴퓨터에 부착된 물리적인 장치들을 디바이스 드라이버를 거쳐 파일 형태로 접근 가능합니다. 그러한 장치들을 나타내는 파일들을 담고 있는 디렉토리 입니다.
*/etc : 운영체제나 운영체제 위에서 동작하는 서비스의 설정 파일들을 담고 있는 디렉토리 입니다.
*/home : 각 일반 유저의 홈 디렉토리를 담고 있는 디렉토리 입니다. 일반 유저들은 각기 자신만의 홈 디렉토리를 가지고 있습니다. 예를 들어 dream 유저의 홈 디렉토리는 /home/dream 입니다.
*/lib : 시스템에 필요한 라이브러리 파일들을 담고 있는 디렉토리 입니다. /bin 이나 /sbin 에 존재하는 프로그램이 필요로 하는 동적 라이브러리 파일이 /lib 디렉토리에 존재합니다.
*/opt : 소프트웨어 패키지들을 담는 디렉토리 입니다.
*/proc : 리눅스 커널 자원에 접근할 수 있는 파일과 프로세스를 나타내는 파일을 담고 있습니다.
*/root : root 유저의 홈 디렉토리 입니다.
*/sbin : /bin 디렉토리와 마찬가지로 기본적인 유저 명령어나 프로그램을 가지고 있는 디렉토리입니다. /sbin은 root 유저가 사용할 수 있는 명령어나 프로그램을 가지고 있습니다.
*/tmp : 유저나 프로그램이 임시로 파일을 생성해야할 때 사용할 수 있는 디렉토리 입니다. 본 디렉토리에 오래 존재했던 파일들은 자동으로 삭제되므로 주의하여 사용해야 합니다.
*/usr : 사용자 바이너리, 문서, 라이브러리, 헤더 파일 등을 담고 있는 디렉토리입니다.
*/var : 프로그램이나 시스템이 실시간으로 가변적인 파일을 사용하고 저장해야 할 때 활용하는 디렉토리 입니다. 예를 들어 /var/log 에는 다양한 로그 파일이 저장됩니다.
